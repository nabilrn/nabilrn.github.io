# Contributing

This repository is maintained as my personal portfolio.

External code contributions and pull requests are not accepted. The repository is not operated as a collaborative community project, and feature work is driven by the portfolio owner's own needs.

You are welcome to fork the repository, copy it, modify it, redesign it, and maintain your own version under the terms of the [MIT License](LICENSE).

If you find the project useful, a GitHub star is appreciated, but it is not required by the license.

For security-sensitive issues involving the deployed portfolio or metrics service, please avoid publishing secrets, credentials, tokens, or private infrastructure details in public discussions.
