> *“最优秀的技术往往是在幕后默默运作的技术。我们每天都在使用它，却几乎不知道它是谁创造的。”*

如果我问，**“你听说过 Linux 吗？”**，很可能大多数人都会回答听说过。特别是如果你在科技领域工作或学习，Linux 这个名字几乎肯定出现过 - 无论是在学习编程、管理服务器、使用云计算、运行 Docker，还是仅仅听说过 Ubuntu 这个名字时。但如果我接着问，**“谁创造了 Linux？”**，我敢肯定能回答上来的人会少得多。他的名字叫 **林纳斯·托瓦兹（Linus Torvalds）**。

有趣的是，我也是在过去几年才真正了解这个人，尽管我几乎每天都在使用诞生于他作品的技术。起初，我以为林纳斯是那种经常出现在媒体上的典型科技创始人。我脑海中浮现的是一个建立了一家估值数十亿美元的公司、经常在各种会议上发表主题演讲、或者活跃于在互联网上打造个人品牌的人。事实证明我错了。我发现的恰恰是一位非常朴素的软件工程师。他很少谈论自己，不追求名气，也不忙着贩卖梦想。他只是喜欢解决问题。

我越是阅读他的故事，就越意识到科技世界不仅仅是由 Google、微软、苹果、亚马逊或 Meta 这样的大公司建立的。在这一切的背后，有成千上万甚至数百万的工程师在默默无闻地工作。他们编写代码、修复漏洞、构建基础，然后将它们分享出来，让其他人能够构建更伟大的事物。有许多名字值得尊敬，例如致力于 GNU 项目的理查德·斯托曼（Richard Stallman）、创造了万维网的蒂姆·伯纳斯-李（Tim Berners-Lee）、Python 之父吉多·范罗苏姆（Guido van Rossum），以及 JavaScript 的创造者布兰登·艾克（Brendan Eich）。但对我个人而言，林纳斯·托瓦兹始终有着特殊的地位。

不是因为 Linux 是最受欢迎的操作系统，也不是因为 Git 成为了行业标准，而是因为他的思维方式。他看起来从来不像是那种试图改变世界的人；他只是不断地解决一个又一个问题。讽刺的是，正是这样的人最终真正改变了世界。


## 一个改变世界的业余项目

让我们回到 1991 年。那时，林纳斯·托瓦兹还是芬兰赫尔辛基大学计算机科学专业的一名学生。像许多其他工科学生一样，他喜欢用电脑做实验。当时他使用的操作系统之一是 **MINIX**，这是一个由安德鲁·塔能鲍姆（Andrew Tanenbaum）教授为了教学目的而创建的基于 UNIX 的操作系统。MINIX 非常适合学习，但是林纳斯觉得这个操作系统有很多局限性。有很多东西他想改变，但却无法自由地做到。

大多数人可能就止步于此了，仅仅抱怨两句，或者等待别人去修复它。但是林纳斯选择了一条不同的路，开始编写自己的操作系统。不是为了出售，不是为了创业，也不是因为想出名。他只想做一个能满足自己需求的操作系统。仔细想来，这个理由听起来非常简单，但历史往往始于简单的理由。

1991 年 8 月 25 日，林纳斯向 Usenet 论坛发送了一条消息，这如今已成为开源历史上最著名的名言之一：
> *“我正在做一个（免费的）操作系统（只是个业余爱好，不会像 GNU 那样庞大和专业）。”*

这句话可能是科技史上最不准确的预测之一。*“只是个业余爱好。”* 如今，几乎无法想象一个没有 Linux 的世界。在它的源代码向公众开放之后，来自世界各地的开发者开始参与贡献。有的修复漏洞、添加驱动程序、提高性能、编写文档，或者帮助进行测试。一个人变成了十个人，十个变成了一百个，一百个变成了数千个，然后是数万个。

Linux 慢慢从一个个人项目变成了软件历史上最大的协作项目之一。有趣的是，林纳斯并没有试图自己做完所有事情。他明白，如此庞大的项目只有在许多人共同拥有并参与贡献的情况下才能发展。也许这就是为什么 Linux 能够存活三十多年，并持续发展至今的原因之一。


## Linux 无处不在，尽管我们很少注意到

如果有人问：“我们使用 Linux 的频率有多高？” 答案可能比我们想象的还要频繁。我们每天访问的大多数网站都运行在 Linux 服务器上。绝大多数现代云服务都以 Linux 为基础 - 从 AWS、Google Cloud、Microsoft Azure、Oracle Cloud 到许多其他云提供商，它们都在 Linux 上运行其大部分基础设施。世界上每一部 Android 手机也都使用 Linux 内核，这意味着每天使用的数十亿部智能手机都以 Linux 作为其操作系统的核心。

不仅如此，世界上最快的超级计算机也使用 Linux。它被用于连接互联网流量的路由器和交换机，以及智能电视、物联网设备、摄像头、工业系统和许多我们可能从未意识到的嵌入式设备中。具有讽刺意味的是，大多数科技用户从未见过 Linux 的标志。他们只是打开应用程序、观看 YouTube、发送消息、使用社交媒体、将文件保存到云端，或者使用 AI 服务，所有这一切都感觉如此平常。然而在幕后，极有可能是 Linux 服务器在不停地运转。

在我看来，这才是真正成功的技术的定义。不是最常被推广的技术，而是变得如此重要以至于它的存在感觉是“隐形”的技术。当一个基础工作得非常好的时候，人们就不会再去想这个基础了；他们只是享受建立在它之上的建筑。而 Linux 就是现代数字世界最伟大的基石之一。


## 不仅仅满足于 Linux，林纳斯还创造了 Git

如果林纳斯的故事到 Linux 就结束了，我相信他的名字仍然会被载入科技史册。但事实证明他的贡献还没有结束。大约在 2005 年，Linux 的开发已经吸引了来自世界各地的数千名开发者，因此新的问题出现了：数千人如何才能在不把一切搞砸的情况下，在同一套数百万行的代码上协同工作？当时的现有版本控制工具无法满足 Linux 开发的需求。

有些人可能会寻找替代方案，有些人可能会等待别人的解决方案。但林纳斯做了和以前一样的事情：他构建了自己的解决方案。结果就是 **Git**。如今，几乎所有的软件工程师都知道 Git。GitHub、GitLab、Bitbucket、Azure DevOps 以及各种现代协作平台都是建立在 Git 生态系统之上的。分支（branch）、合并（merge）、拉取请求（pull request）、代码审查（code review），直到提交历史（commit history） - 所有这些对现代开发者来说司空见惯的概念，都因为 Git 而变得容易得多。

很难想象如果没有 Git，开源世界的发展会变成什么样。由于这个工具的存在，全世界成千上万有着数百万贡献者的项目得以更有条理地发展。有趣的是，Git 的诞生也不是因为林纳斯想开发一款新产品；Git 的诞生是因为有一个真正需要解决的问题。我越是阅读他的人生旅程，就越能看到同样的模式：发现问题，理解问题，然后构建解决方案 - 不是为了出名，而是因为那个问题确实值得解决。


## 我学到的教训

我越是了解林纳斯·托瓦兹，就越意识到最大的教训不是关于 Linux 或 Git，而是关于**心态**。在这个每个人都在竞相打造个人品牌、追逐粉丝、渴望爆红，并想被称为“创造了某个东西的人”的时代，林纳斯却展示了一条完全不同的道路。他让自己的作品说话。他从没说过他想改变世界，但世界却因为他所构建的东西而改变了。

老实说，了解林纳斯的故事让我变得更加谦逊。我意识到，在科技世界里，我还只是个无名小卒。还有那么多我不知道的事情，还有那么多伟大的工程师，他们的名字可能永远不会出现在媒体上，但他们的贡献支撑着我们每天使用的互联网。奇怪的是，这种认识并没有让我感到自卑，恰恰相反 - 这让我更有动力去继续学习。

因为也许，所有伟大的贡献都始于一种简单的好奇心。我不知道有一天我是否能创造出像 Linux 或 Git 那样影响深远的东西；极有可能不会。但我希望有一天，我能以同样的方式，为科技世界做出一点贡献，无论多么微小：保持好奇，专注解决问题，保持谦逊，让作品的声音比我自己的名字更响亮。
